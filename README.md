📊 About the Project

Hi! I'm Ayush, and I created this Excel dashboard to analyze Spotify playlist data and understand different patterns related to music genres, popularity, playtime, and explicit content.

The project uses Microsoft Excel to organize the data, create summary tables, and build an interactive-looking dashboard for presenting the analysis in a simple and visual way.

🎯 Project Objectives

The main purpose of this project is to analyze:

🎶 Popularity of different music genres
⏱️ Total playtime for each genre
🔞 Explicit vs. non-explicit tracks
📈 Popularity based on explicit content
🎵 Number of tracks in the dataset
📊 Overall genre-wise performance
